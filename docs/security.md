# Security

- Never commit secrets.
- Use a dedicated secret manager in production.
- Apply least privilege to every integration and agent.
- Separate tenant/company/project data.
- Encrypt sensitive data at rest and in transit.
- Keep immutable audit records for important actions.
- Require governance approval for high-risk operations.
- Keep outbound email approval-required until explicit policy allows automation.
- Protect the main branch.
- Use bounded retries and rollback for autonomous recovery.
- Maintain backups and recovery procedures.
