# AI Agency

Autonomous AI-powered B2B web agency platform.

## Core principles
- Claude is the sole AI reasoning layer.
- Human ownership, governance, approvals, and emergency stop remain mandatory.
- Quality-first lead generation; the 50/day target is not a reason to lower quality.
- Free-first infrastructure with cost controls and no unexpected spending.
- Company and project data are isolated by default.
- Secrets are never committed to source control.
- Every important autonomous action is auditable.
- Client maintenance subscriptions are not offered by default; internal reliability monitoring remains enabled.

## Architecture
Command Center → Orchestrator → Specialized Agents → Claude → Tools/Integrations → Audit/Reporting.

See [docs/architecture.md](docs/architecture.md).
